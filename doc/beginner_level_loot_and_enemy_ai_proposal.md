## 敌人 AI

### 当前实现核对

- 当前 `EnemyAI` 会直接以曼哈顿距离选择最近玩家，尚未做感知判定或巡逻；所有敌人都知道玩家位置。
- 敌人的攻击距离**当前没有距离衰减**：`Unit.get_attack_distance_profile()` 固定返回 `damage_multiplier = 1.0` 与基础命中。虽然战斗结算器支持距离倍率，但 `conf/enemies.json` 没有敌方 `distance_bands`。
- 玩家武器已有距离分段与伤害／命中衰减。因此本轮 AI 实现应保持敌人无距离衰减，后续若要加入，只需在敌人配置补齐与玩家武器兼容的 `distance_bands` 字段。

### 本轮状态优先级

每个敌方回合只执行一个主状态，优先级固定如下：

1. `回撤`：仅允许回撤的单位，生命低于阈值且本回合触发概率成功。
2. `交战`：感知到其他阵营单位时，选定一个目标并尝试进入射程后连续攻击。
3. `巡逻`：未感知到目标时，随机移动。
4. `待机`：无可走格、没有足够 AP 或配置禁用巡逻时结束回合。

目标统一定义为 `faction != enemy.faction` 的有效单位；当前战场只有玩家阵营，未来可自然扩展到友军／第三方阵营。

### 感知方案

每个敌人**只选择一种**感知方式：路径 AP、曼哈顿距离或切比雪夫距离。候选目标按该方式对应的数值升序选择；完全并列时按场景树顺序打破平局。

#### A. 路径 AP 感知

- 复用 `Pathfinder` 的四向移动、墙体、障碍、楼梯与楼层切换规则。
- `range = N` 且 `mode = path_ap` 表示从敌人当前位置出发，在最多 N 步／N AP 的合法路径内感知到其他阵营单位。
- `allow_cross_level = true` 时允许通过现有楼梯邻接规则跨层；为 `false` 时搜索只保留敌人当前楼层。
- 感知查询需要把“目标占格”视为可检测终点，而不能因目标单位占格不可走而漏检；实现时应在 BFS 扩展邻居时先检查单位，再决定是否继续入队。
- 此方式会受绕路、墙体、封路与楼梯影响，适合“能走到／能逼近到”的近距离警戒。

#### B. 以自身为中心的直接距离感知

直接距离不走寻路，只比较格子坐标；选择此方案的敌人必须在以下两种距离中指定其一：

| 计算方式 | 公式 | 用途 |
| --- | --- | --- |
| `manhattan` | `abs(dx) + abs(dy)` | 菱形范围，适合近战、巷道与保守警戒。 |
| `chebyshev` | `max(abs(dx), abs(dy))` | 方形范围，和现有战斗距离结算一致，适合远程警戒。 |

- `mode = manhattan` 或 `mode = chebyshev`，并使用唯一的 `range = N`；同一敌人不会同时启用两种直接距离。
- `allow_cross_level = false` 时只检测同层单位。
- `allow_cross_level = true` 时允许检测其他楼层；跨层只作为感知开关，不额外增加距离成本。
- 直接距离感知不要求视线通畅；“能否开火”仍由既有 `BulletRange` 在交战阶段单独判断。

### 巡逻

- 未感知到目标时，敌人随机选择 `0～当前剩余 AP` 作为本回合巡逻路径预算；上限完全由敌人自身的 `ap_max`／当前 AP 决定，不增加单独配置。
- 从 `Pathfinder.bfs()` 得到预算内可达节点，随机选一个节点作为终点，再按最短路径逐格移动。
- `0 AP` 是合法结果，代表原地待机；没有可达节点也原地待机。
- 巡逻不会预留攻击 AP，也不会在同一回合改为追击；下一回合重新感知。这让无目标行为保持可预测且便于调试。

### 交战

1. 感知到目标后，若目标已在既有 `BulletRange.can_reach_cell()` 的有效射程与枪线内，原地交战。
2. 若不在射程内，枚举目标周围所有“可开火格”：该格可走、敌人可寻路抵达、且从该格到目标满足武器射程与枪线。
3. 选择路径最短的可开火格；移动时最多使用“进入该格”所需 AP，不额外追击。
4. 到达可开火格后，`while AP >= attack_cost` 持续攻击同一目标，直到 AP 不足、目标死亡或枪线失效。
5. 若当前 AP 无法到达任何可开火格，则朝路径最短的可开火格移动尽可能远，耗尽可用 AP；本回合不攻击。

本轮不实现保持最佳距离、压制、换掩体、侧翼或最后目击点搜索，以避免基本战斗行为与后续战术层混杂。

### 低血量回撤

仅 `街区掠夺兵` 和 `斥候掠夺者` 启用；其余敌人本轮不回撤。

- 触发时机：敌人回合开始、感知和交战前。
- 条件：`current_hp / max_hp < 0.20`。
- 概率：每个满足条件的回合独立掷一次，`50%` 成功即进入本回合 `回撤` 状态。
- 回撤不攻击；使用当前所有 AP 移动。
- 候选格为当前 AP 内所有可达格，排序规则：
  1. 优先选择不在玩家**当前位置**武器射程与枪线内的格（调用现有 `BulletRange`，使用玩家当前武器范围）。
  2. 在安全候选中，选择与玩家当前位置 `chebyshev` 距离最大的格。
  3. 若没有安全候选，选择距离最大的合法格。
  4. 完全并列时随机选择，避免多个单位每次走出完全相同的路径。
- 这同时满足“逃离玩家”和“躲开玩家当前枪线”；不预测玩家下一回合的位置，也不加入复杂掩体评分。

### 配置草案

建议在 `conf/enemies.json` 的敌人条目新增 `ai`；`perception` 只允许一个 `mode`。`perception.range` 是感知数值：当 `mode = path_ap` 时表示感知 AP；当 `mode = manhattan` 或 `chebyshev` 时表示对应的格子距离。巡逻不需要配置字段，直接使用敌人当前 AP。

```json
"ai": {
  "perception": {
    "mode": "path_ap",
    "range": 6,
    "allow_cross_level": true
  },
  "retreat": {
    "enabled": true,
    "hp_ratio_threshold": 0.20,
    "trigger_chance": 0.50
  }
}
```

| 敌人 | 感知方案 | 感知 AP | 感知距离 | 可跨层 | 回撤 |

| 斥候掠夺者 | 切比雪夫 | — | 5 | 否 | 生命 <20%，50% |
| 护盾掠夺者 | 路径 AP | 5 | — | 是 | 不启用 |

新手关仅启用两名街区掠夺兵与一名斥候掠夺者：先让玩家学习“进入敌人感知范围后会被逼近并连续攻击”的节奏，再逐关引入其他敌人。
