# 战场战斗、伤口、护具与容器规范

> 版本：2026-09-17（已审核，后续代码必须以本文为准）。
> 关联：`warehouse_art_manifest.md`、`crafting_design.md`、`battlefield_inventory_implementation_plan.md`。

## 1. 范围与废弃规则

- 删除旧的 `steady_aim`、`combat_stimulant`、`guarded`、`pyroxene_burn`、`suppressed`、`exposed` 状态。
- 删除暴击率与暴击倍率；武器、干员、配件均不得再拥有 `crit_chance` 或 `crit_multiplier`。
- 战斗中只保留两种伤口状态：`bleeding` 流血与 `fractured` 骨折。
- 物品的直接恢复、行动点恢复等不是 Buff；它们在使用结算时即时生效，不创建持续状态。

## 2. 伤口状态与治疗

| 状态 | 触发部位 | 持续方式 | 回合效果 | 可治疗物品 |
| --- | --- | --- | --- | --- |
| `bleeding` 流血 | 无护具 / 护具耗尽的身体、四肢命中 | 永久；最多 3 层 | 每层在持有者回合开始时受到 5 点真伤 | 清创敷料、急救包、创伤处理包、前线救援套件 |
| `fractured` 骨折 | 无护具 / 护具耗尽的四肢命中 | 永久；不可叠加 | 基础 AP 上限 -2 | 无菌绷带组、战地医疗箱、创伤处理包、前线救援套件 |

### 2.1 使用医疗物品

- 医疗物品只能从已装备背包中右键使用；菜单文案固定为 `使用（1 AP）`。
- 使用前必须检查当前角色是否至少有一项效果可生效：可恢复生命、可移除流血、可移除骨折。三者均无效时禁用菜单项并不消耗 AP 或物品。
- 成功使用时先花 1 AP，再结算治疗，再消耗物品；若物品有多个效果，所有可生效效果同时执行。

| 物品 ID | 治疗效果 | 可用条件 |
| --- | --- | --- |
| `consumable_dried_medicine_02` | 恢复 8 HP | 当前 HP 未满 |
| `consumable_debridement_dressing_03` | 移除全部 `bleeding` 层数 | 至少有 1 层流血 |
| `consumable_sterile_bandage_04` | 移除 `fractured` | 当前骨折 |
| `consumable_medkit_01` | 恢复 40 HP；移除 1 层 `bleeding` | HP 未满或流血 |
| `consumable_field_medical_case_06` | 恢复 80 HP；移除 `fractured` | HP 未满或骨折 |
| `consumable_trauma_kit_07` | 恢复 100 HP；移除 1 层 `bleeding` 与 `fractured` | HP 未满、流血或骨折 |
| `consumable_frontline_rescue_08` | 恢复至满 HP；移除流血和骨折 | HP 未满、流血或骨折 |

## 3. 命中与部位结算

### 3.1 命中判定

1. 先用既有弹道和距离规则确认可攻击。
2. 依据武器的 `distance_bands` 读取当前格距的伤害系数与基础命中率；再叠加干员/配件命中修正并扣除目标闪避。
3. `命中率 = clamp(距离档基础命中 + 干员命中修正 + 配件命中修正 - 目标闪避, 20, 95)`。
4. 未命中即结束；命中后进入部位抽取，不存在暴击二次判定。

### 3.1.1 贝妮武器距离档

| 武器 | 格距 | 伤害系数 | 基础命中率 |
| --- | --- | ---: | ---: |
| 防卫者-9 | 1～2 | 0.95 | 88 |
| 防卫者-9 | 3～4 | 0.80 | 78 |
| 防卫者-9 | 5 | 0.60 | 64 |
| 野兔跳跃者 | 1～2 | 0.95 | 85 |
| 野兔跳跃者 | 3～4 | 0.82 | 77 |
| 野兔跳跃者 | 5～6 | 0.62 | 65 |
| 黎明初霁 | 1～2 | 1.00 | 92 |
| 黎明初霁 | 3～4 | 0.85 | 83 |
| 黎明初霁 | 5～6 | 0.70 | 74 |

最终命中率最低 20、最高 95。对应数据写入武器 JSON 的 `distance_bands`，而非写死在角色脚本中。

### 3.2 部位指数（不是百分比）

每个攻击来源可提供三个非负整数：`head_index`、`body_index`、`limb_index`。最终指数按来源相加：

`最终部位指数 = 干员基础指数 + 武器指数 + 已装备配件修正 + 临时战术修正`。

然后按权重抽取部位：`头部权重 / 三项总和`、`身体权重 / 三项总和`、`四肢权重 / 三项总和`。三项不需要相加为 100，也不应在 UI 中表述为百分比。

建议起始基线：

| 来源 | 头部指数 | 身体指数 | 四肢指数 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 贝妮基础 | 10 | 65 | 25 | 以稳定打身体为主 |
| 防卫者-9 | 0 | 10 | 0 | 紧凑 SMG 的近中距离压制 |
| 野兔跳跃者 | 4 | 8 | 0 | 瞄具与操控改善头部窗口 |
| 黎明初霁 | 8 | 6 | 0 | 高精度共鸣 SMG |

### 3.3 伤害

- `基础伤害 = round((武器 attack_power + 干员 damage_flat + 配件 damage_flat) × 距离档伤害系数)`。
- 命中部位后只乘固定部位系数，不叠加暴击、不叠加隐藏伤害随机数：

| 部位 | 伤害系数 | 默认护具 |
| --- | ---: | --- |
| 头部 | ×1.6 | 头盔 |
| 身体 | ×1.0 | 护甲 |
| 四肢 | ×0.7 | 无 |

`部位原始伤害 = round(基础伤害 × 部位系数)`。

## 4. 头盔与护甲：绝对吸收值

护具不再提供百分比减伤或平滑减伤。`warehouse_art_manifest.md` 中的护甲值就是该装备的 `max_armor` 与初始 `current_armor`；每件护具另有独立的 `per_hit_absorb`，限制一次攻击最多可吸收多少伤害。

1. 头部命中只检查头盔；身体命中只检查护甲；四肢默认没有护具。
2. `吸收伤害 = min(部位原始伤害, 对应护具 current_armor, 对应护具 per_hit_absorb)`。
3. `实际 HP 伤害 = 部位原始伤害 - 吸收伤害`。
4. `current_armor -= 吸收伤害`。数值归零后该部位不再吸收任何伤害，之后命中全部为真伤。
5. 护具不足以全额吸收、且本次攻击将其打到 0 时，溢出部分照常伤害 HP，并视为“护具耗尽命中”参与伤口判定。

### 4.1 当前装备数值（直接取自仓库清单）

| 槽位 | 装备 | ID | 最大 / 初始吸收值 | 单次吸收上限 |
| --- | --- | --- | ---: | ---: |
| 护甲 Lv5 | 轻型护甲组件 | `armor_light_component_05` | 20 | 10 |
| 护甲 Lv6 | 模块化护甲 | `armor_modular_06` | 40 | 20 |
| 护甲 Lv8 | 前哨防护护甲 | `armor_outpost_defense_08` | 180 | 60 |
| 头盔 Lv4 | 加固盔体 | `helmet_reinforced_shell_04` | 8 | 4 |
| 头盔 Lv6 | 模块化战术头盔 | `helmet_modular_tactical_06` | 35 | 12 |
| 头盔 Lv7 | 晶纤维战术头盔 | `helmet_crystal_fiber_07` | 80 | 30 |
| 头盔 Lv8 | 前哨防护头盔 | `helmet_outpost_defense_08` | 160 | 50 |

## 5. 无护具命中的伤口概率

只有以下情况才允许判定伤口：

- 被命中部位从一开始没有对应护具；
- 对应护具在攻击前 `current_armor = 0`；
- 对应护具在本次攻击中耗尽，且有溢出 HP 伤害。

每个候选伤口的最终概率：

`最终概率 = clamp(武器基础概率 + 干员伤口加成 + 配件伤口加成 + 部位加成, 0, 100)`。

- `bleeding` 只能由身体或四肢的无护具命中触发。
- `fractured` 只能由四肢的无护具命中触发。
- 敌人、干员、武器与配件均可声明候选伤口及其概率；没有候选配置时不会凭空造成伤口。

建议配置结构：

```json
"unprotected_debuffs": [
  {"id": "bleeding", "chance": 18, "locations": ["body", "limb"]},
  {"id": "fractured", "chance": 12, "locations": ["limb"]}
]
```

## 6. 容器搜索与本局持久化

- 右键任意容器弹出菜单。首次未搜索容器显示 `搜索（N AP）`；已经打开的容器显示 `继续搜索（免费）`。
- 菜单始终明确显示 AP 消耗；不在 1 格攻击射线内、AP 不足或容器搜空时，按钮禁用并给出原因。
- 首次搜索通过后，容器切为打开图标并创建唯一的本局临时容器 ID；掉落只写入一次。
- 关闭物资面板只是隐藏；不得清除该容器的临时物资。再次搜索同一个容器时必须看到剩余物品。
- 当前战局结束时统一清除所有临时容器；未带走的物品丢弃。
- 容器的 `can_walk` 复用 TileSet 同名属性：为 `true` 时角色可站在同格，且弹道可穿过；敌人死亡生成的战利品箱固定为 `true`。此时右键角色会在行动菜单中显示搜索入口。

## 7. 拖拽丢弃与地面丢弃物

- 任何可拖拽物品开始拖拽时，屏幕最右侧出现从顶部到屏幕底部的窄条丢弃面板，带垃圾桶图标。
- 默认颜色沿用当前战术面板的深蓝青配色；拖到面板上时转为红色系。
- 松开时弹出确认框。确认后，物品不销毁，而是转移到角色当前格、当前楼层的 `丢弃物` 容器。
- 丢弃物视觉节点挂在该层 `obstacle` 下，但不阻挡移动或弹道，避免角色把物品丢在脚下后无法移动。
- 同一格同一层只有一个丢弃物容器，可容纳多个物品；其搜索免费、可重复打开，临时面板标题固定为“丢弃物”。
- 丢弃物为空时移除其视觉节点；本局结束时与其他战场容器一起清理。

## 8. 数据字段迁移

| 旧字段 | 处理 |
| --- | --- |
| `crit_chance` / `crit_multiplier` | 删除 |
| `on_hit_effect_id` / `on_hit_chance` | 替换为 `unprotected_debuffs` |
| `armor` 平滑减伤 | 删除；装备实例 `current_armor` 作为绝对可吸收值 |
| 旧短时 Buff/Debuff | 删除，仅保留永久流血与骨折 |
| `battle_effect_id` | 医疗物品逐步迁移到 `battle_use` 结构，支持治疗、移除伤口与 1 AP 使用成本 |
| `distance_bands` | 武器按格距声明伤害系数与基础命中率；缺失时才回退到旧 `accuracy` |
| `per_hit_absorb` | 护具每次受击可吸收的绝对伤害上限 |

## 9. 攻击结算日志

每次玩家或敌方攻击均输出两条日志：

1. 中文可读日志：攻击方干员、武器、已装配件、当前 Buff / Debuff、各来源数值、加成后总数值、距离档、命中掷骰、部位、护具吸收、伤口判定与最终伤害。
2. 原始 JSON：保留完整快照、命中公式、伤害公式和每个伤口候选的概率 / 掷骰，便于调试与回放。
