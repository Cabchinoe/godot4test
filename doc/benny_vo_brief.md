## 1. 角色卡（给配音演员）

**贝妮（Benny）**，19 岁，来自断裂带边缘的温室聚落「白垩谷」。
晶涌爆发那晚，母亲把最后一箱种子塞给她，让她「带出去种」。她走了十一天，是撤离名单上最后一个名字。
现在是前哨站第 7 侦察－补给小队队员，也是玩家主控苏醒后的看护员兼向导。

**她不是最强的那个，但永远是最后一个离开战场的人。**

三层性格：

| 层 | 表现 |
|---|---|
| 日常 | 温和、元气、有点小天然。会认真给每一株嫩芽起名字，把配给糖偷偷留给哨兵；偶尔冒失，但很快自己调整回来。 |
| 工作 | 努力型可靠。路线、补给、撤离顺序提前记到烂熟；犯小错时先慌半拍，立刻修正，不长期自责。 |
| 战场 | 带着「把种子和人都带回去」的使命，还没完全准备好就被迫上战场。会失误，但不会停在失误里——声音要听得出**努力和韧性**，不是低沉疲惫型。 |

**形象**：银白色短发，一对白色兔耳，红宝石色眼睛，近黑／酒红色战术耳麦，冷白灰立领冲锋衣。整体是二次元赛璐璐平涂的战术干员感，**不是甜美偶像、不是成熟御姐**。

## 2. 音色与演绎规格

### 音色

| 项 | 要求 | 排除 |
|---|---|---|
| 年龄感 | 19 岁，偏少女但不幼态 | 不要儿童音、不要少女音过甜 |
| 音区 | 中音区偏亮 | 不要低沉、沙哑、疲惫 |
| 质感 | 清亮有精神，干净、咬字清楚 | 不要气声过多、不要含糊 |
| 整体气质 | 元气、可靠、努力型 | **不是甜腻萌音，不是冷硬御姐，不是播音腔** |
| 咬字 | 清楚利落，辅音有力 | 不要含混、不要拖字 |

### 语速与节奏

| 场景 | 语速 | 说明 |
|---|---|---|
| 日常 | 正常～略快 | 句尾可以轻轻上扬，但不要蹦跳式卖萌 |
| 工作 | 正常 | 清晰、干脆，像在确认事项 |
| 战斗 | 略快（比日常快一档） | 短句、清晰、有推进感，**不喊口号、不长时间嘶吼** |
| 情绪高点 | 中等 | 认真、坚定、带一点鼓励感 |
| 疼痛 | 短促 | 吸气／闷哼后立刻调整呼吸，**不要哭腔、不要拖长** |
| 小失误 | 先慌半拍 | 然后用一句「没事／再来／我调整好了」拉回来，不持续自责 |

### 禁忌

- 低沉疲惫声线
- 动漫式尖叫
- 过度撒娇
- 长篇说教
- 频繁叹气
- 播音腔／念稿感

## 3. 录音规格

### 设备与环境

- 安静房间，关闭空调、风扇、手机；不要有混响（避免录音混响影响后期与复刻）
- 麦克风与嘴距离 15～20 cm，略偏一侧避免喷麦
- 佩戴耳机监听，**不要开任何效果插件**（混响、压缩、降噪一律关）

### 交付格式

| 用途 | 格式 | 规格 |
|---|---|---|
| **成品**（游戏用） | WAV | 44.1 kHz / 16 bit / **单声道**，未压缩未归一 |
| **母版**（留存用） | WAV | 48 kHz / 24 bit / 单声道 |

- 干声：**不要混响、不要压缩、不要降噪、不要背景音乐、不要音效**
- 峰值：**-6 dBFS**（留足余量，Godot 侧会再统一做响度归一到 -16 LUFS）
- 每条之间留 **0.5 秒静音**；每条前后各留 0.5 秒
- 不要剪切掉呼吸和起音的余量

### 命名

```
voice_benny_<scene>_<variant>.wav
```

例：`voice_benny_cutin_in_01.wav`、`voice_benny_hit_02.wav`
（`<scene>` 与 `<variant>` 的完整对照见第 5 节及 `doc/benny_voice_lines.md` 第 2 节）

## 4. 录制方式：两种，建议都做

### 方式 A：直接录成品（质量最高）

按第 5 节台词表逐条录制，交付 WAV。这是最终游戏资产。

### 方式 B：录 60 秒参考音频（用于 AI 复刻量产）

**如果后续台词要大量扩充**（变体台词、剧情长对话、羁绊事件），只靠逐条真人录制成本会很高。此时需要一段 60 秒左右的**自然说话**参考音频，用于音色复刻：

- 时长 **30～90 秒**（MiniMax 要求 10 秒～5 分钟，建议 60 秒）
- 格式 mp3 / m4a / wav，≤ 20 MB
- 内容：**用平常说话的语调念一段你的日常对话**（讲今天做了什么、随便聊聊）
- **关键：不要念游戏台词、不要念得像播音腔**——刻意表演过的声音会污染复刻结果，克隆出来会带着播音腔
- 环境同样要求安静、无混响

复刻前提条件（当前账号尚未满足）：

| 条件 | 状态 | 说明 |
|---|---|---|
| 个人或企业实名认证 | ❌ 未完成 | 复刻接口返回 `2038 voice clone user forbidden`，需在 <https://platform.minimax.cn/user-center/basic-information> 完成认证 |
| 复刻音色 7 天有效期 | ⚠️ 注意 | 复刻得到的音色若 7 天内未正式调用，系统会删除。拿到 voice_id 后要立刻用它生成正式台词 |

**推荐组合**：方式 A 录 12 条主线成品 + 方式 B 留 60 秒参考音频。后续变体台词用复刻音色 AI 量产，音色与主线一致。

## 7. 验收清单

交稿后逐条核对：

- [ ] 文件名符合 `voice_benny_<scene>_<variant>.wav`
- [ ] 44.1 kHz / 16 bit / 单声道 WAV
- [ ] 峰值 ≤ -6 dBFS，无削波
- [ ] 无混响、无压缩、无背景音、无音效
- [ ] 每条之间有静音间隔，无剪接爆音
- [ ] 每条都单独可辨，**没有把两条录在一起**
- [ ] 12 条主线齐全
- [ ] 音色统一：同一条角色在不同情绪下仍是同一个人
- [ ] 「我先进去，你压后。」具备战场指令感（干练、果断、不喊）
- [ ] 「唔。」是短促闷哼而非拖长呻吟
- [ ] 受伤类台词**无哭腔**
- [ ] 全部为标准普通话，无方言口音、无英文

## 8. 落地方式

1. 录音 → 交 WAV
2. 放入 `Art/audio/sfx/_review/`（**不要直接进正式目录**）
3. 我做技术校验（格式、峰值、削波、时长）+ 接入 `conf/battle/sfx_bindings.json`
4. 你试听确认后转正式文件 `Art/audio/sfx/`，接绑定，清理 review 区
5. Godot 导入设置：勾选 **Normalize**（统一响度），Loop 关闭

> ⚠️ 当前代码里只有 `voice_heal` 一个语音 cue 已接线，其余 11 个 cue 的触发点尚未接入
> （`units.benny.select_player` / `bleed_apply` / `fracture_apply` / `battle_cutin_in` / `unit_down` /
> `player_voice.battle_victory` / `battle_defeat` / `evac_confirm` / `evac_success` / `evac_fail`）。
> 音频录好后需要一并补上代码接线，否则不会响。详见 `doc/benny_voice_lines.md` 第 2 节与
> `Script/battle/battle_sfx.gd` 的 `resolve_binding()`。
