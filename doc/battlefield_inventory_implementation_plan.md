# 战场角色面板、搜索与丢弃物方案

> 版本：2026-09-18。容器、临时物资和地面丢弃物均只在当前战局存在，不写入常规存档。

## 1. 容器状态

每个地图容器、敌人战利品箱和地面丢弃物都有稳定的本局 `resource_id`，并绑定一个唯一的 `TemporaryContainer`：

| 状态 | 首次搜索 | 后续搜索 | 面板关闭 | 战局结束 |
| --- | --- | --- | --- | --- |
| 普通容器 | 需满足同层 + 1 格攻击射线，花费 `open_ap_cost` | 0 AP 查看剩余物品 | 只隐藏，不清空物品 | 清空未带走物品 |
| 敌人战利品箱 | 同普通容器 | 0 AP 查看 | 同上 | 同上 |
| 丢弃物 | 0 AP | 0 AP | 同上 | 同上 |

首次打开时只向临时容器写入一次配置掉落；以后从背包转走的物品会从该临时容器中移除，因此再次查看时自然保留“已拿走 / 未拿走”状态。

## 2. 右键搜索菜单

- 右键容器显示独立菜单，而非左键立即开启。
- 首次菜单项：`搜索（N AP）`；打开后菜单项：`继续搜索（0 AP）`；已搜空时菜单项：`查看（已空）（0 AP）`。
- 菜单始终显示 AP 成本，统一写作 `N AP`，不使用“免费”字样。
- 只有“不同层”“超出 1 格攻击射线”“AP 不足”会禁用搜索项并显示原因；0 AP 的目标即使已搜空也可以打开面板查看。
- 搜索必须与角色位于同一层，该条件优先于射程判定；1 格可搜索判定复用 `BulletRange` 弹道与墙体规则，打开后的容器仍需要在范围内才能再次查看。
- 动态容器新增 `can_walk`，语义与 TileSet 同名属性一致：`true` 时可跨越且不阻挡弹道，`false` 时同时阻挡移动和弹道。敌方单位死亡产生的战利品箱固定为 `true`。
- 若角色站在同格的 `can_walk = true` 容器上，右键角色的行动菜单会额外出现“搜索 / 继续搜索”，避免被角色本体遮挡而无法点中容器。

### 2.1 同格多容器

- 同一格同层允许并存任意数量的容器（敌人战利品箱、丢弃物、`can_walk = true` 的地图容器），不做合并。默认目标只分两档：没搜过 > 搜过；丢弃物不参与分档，恒定排在最前。同档取绘制在最上层的那个。
- 容器状态变化时（生成、首次打开、搜空）会重排同格兄弟顺序，让优先级最高者绘制在最上层，保证“看到的”就是“点到的”。不使用 `z_index` 分层，避免盖住角色。
- 同格候选 ≥2 个时，右键容器弹出目标列表（标题 `同格 N 个目标`），每行显示名称、状态动词与 AP 成本；不可用的行禁用并给出原因。右键角色的行动菜单显示 `搜索…（同格 N 个）`，点击后关闭行动菜单并弹出同一个列表，两个入口共用一套选择 UI。
- 同格候选只有 1 个时，两个入口的行为与文案与单容器情况完全一致。
- 0 AP 目标（搜过的容器、丢弃物）即使已搜空也允许打开面板查看，不扣 AP，列表行动词显示 `查看（已空）`；只有“不同层”“超出 1 格攻击射线”“AP 不足”会禁用行动项。
- 菜单宽度按最宽一行文字自适应，长容器名不会被截断。
- 行动菜单跳转列表菜单时延迟一帧弹出，避免同帧关闭 + 弹出被窗口失焦逻辑一起关掉。
- 搜索会扣 AP，因此不做“搜完自动切下一个”的隐式轮转，目标必须由玩家在列表中显式选择。

## 3. 医疗物品右键使用

- 仅已装备背包中的医疗消耗品显示右键菜单；菜单项为 `使用（1 AP）`。
- 可用性由 `battle_use` 计算：生命未满、存在流血、存在骨折，任一命中即可使用。
- 成功使用：扣 1 AP → 同时结算全部有效治疗 → 消耗物品 → 刷新背包、状态栏和伤口状态。
- 无任何效果可生效时，按钮禁用，不消耗 AP 或物品。

## 4. 拖拽丢弃

### 4.1 交互

1. 任意可拖拽物品开始拖拽时，右侧显示贴边、从顶部到底部的窄条 `丢弃区`，内含垃圾桶图标。
2. 默认使用战术面板的深蓝青色；鼠标拖入时变为红色系高亮。
3. 在丢弃区松开时弹出确认框：`确认丢弃 <物品名>？`。
4. 确认后，把该物品实例转移到角色当前 `grid + level` 对应的本局“丢弃物”临时容器，而不是删除。

### 4.2 地图表现

- 丢弃物节点挂在当前楼层的 `obstacle` TileMapLayer 下以保证覆盖顺序，其 `can_walk = true`，因此不阻挡移动或弹道。
- 同格同层的多次丢弃合并到同一个“丢弃物”容器。
- 丢弃物搜索为 0 AP；临时面板标题固定为“丢弃物”。
- 容器没有剩余物品时，移除地面视觉节点与本局容器状态。

## 5. 临时物资持久化边界

- `WarehouseService.create_temporary_container()` 会保留同 ID 的已有物品，适合容器反复查看。
- 战斗面板切换搜索目标时不得调用 `clear_temporary_container()`。
- 仅离开战场时调用 `WarehouseService.clear_all_temporary_containers()`，删除未带走实例。
- 转移进背包、装备或配件槽的物品保持由 `InventorySaveData.warehouse_items` 持有，并按正常存档保存。
- 点击结束回合会收起战术面板、临时物资面板、物品使用菜单、丢弃确认框和两类右键行动菜单，但不会清空本局容器库存。
